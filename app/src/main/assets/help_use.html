使用帮助

1. 本软件的作用

本软件主要用于dex中的方法的String类型的参数替换，待替换的参数需要根据规则匹配，而不是全部替换操作。 主要是方便修改，避免手动插入smali指令。 同时提供方法的参数的日志记录功能，方便查看运行情况（无需Root） 支持 native 类型的方法修改和记录参数的功能。 其中关于iApp修改方法见：【iApp通用】iApp软件非服务端验证功能过VIP通用教程

2. 软件需要的权限
  1. 文件存储权限：用于读取和写出dex文件。
  2. 网络权限：用于检测和更新App版本，反馈Bug和建议。
3. 首页介绍

为了方便，首页采用悬浮按钮的方式，按钮的对应功能介绍如下：

  1. 选择apk文件导入
  2. 新建一个方法参数替换的规则
  3. 执行写出操作，首次使用需要申请存储权限
  4. 用于复制的apk的完整路径粘贴，不用手动选择文件，但要确保文件路径正确可访问!(特别是敏感的数据目录)
2. 添加规则功能介绍

  1. 配置是记录该方法的所有参数的日志，还是直接执行修改操作 若是记录的日志操作，那么软件运行时，将会把执行方法的每个参数记录到文件中，记录位置在 Android/data/修改软件的包名/files/Killer/目录下。
  2. 方法签名：输入要修改的方法的签名，例如：Lcom/example/test/MainActivity;->onCreate(Landroid/os/Bundle;)V， 预先提供了六个方法签名，以便修改，可以从mt复制，不会出错。
  3. 方法参数：输入需要修改的参数是该方法的第几个参数，目前只支持String类型的修改!
  4. 匹配值: 输入框输入待修改字符串的匹配规则，例如iApp的判断语句f(sss.vip==true)，那么这里就直接输入sss.vip==true即可
  5. 替换值: 输入要修改的替换值，将匹配值匹配的部分替换为想要的值。例如将判断规则改为true，就是将f(sss.vip==true)替换为true了

4. 修改步骤

步骤1：导入apk文件

步骤2：点击“+”添加修改规则

步骤3：点击执行按钮输出apk文件

5. 常见问题

1：apk文件写出位置

dex文件的写出位置和导入的apk文件位置一致，后缀为killer_sign.apk

2：修改的apk记录的参数日志文件位置

记录的参数日志文件位置在Android/data/修改软件的包名/files/Killer/目录下或者是iAppKiller目录

3: 一个apk执行了两次修改出现闪退情况，可能是缓存bug，建议重启Killer执行修改操作。

这个bug由于优化dex速度导致，后续版本会修复
