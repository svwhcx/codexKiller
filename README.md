# STool

STool is a native Android toolbox app scaffolded with Kotlin, Jetpack Compose, Hilt, DataStore, Room, Retrofit, and OkHttp.

## Requirements

- Android Studio with JDK 17 configured
- Android Gradle Plugin 9.2.0
- Gradle 9.4.1
- compileSdk 36

If JDK 17 is not installed locally, Gradle is configured with the Foojay toolchain resolver so it can provision a matching JDK automatically during sync/build.

## Package

- Application ID: `com.svwh.tools`
- Debug application ID: `com.svwh.tools.debug`
- App name: `STool`

## First Run

Open this folder in Android Studio, let Gradle sync, then run the `app` configuration.
